# GuardPlate
🚗 GuardPlate: Akıllı Araç Tanıma ve Plaka Okuma Sistemi
GuardPlate, trafik kurallarını ihlal eden ağır taşıtların yasak saatlerde geçişini tespit etmeyi amaçlayan yapay zeka destekli bir araç sınıflandırma ve plaka tanıma sistemidir. YOLOv8 ile araç tespiti yapılır, EasyOCR ile plaka okunur ve PostgreSQL veritabanına ihlal kaydı alınır. Kullanıcı dostu arayüz sayesinde sistem gerçek zamanlı olarak kullanılabilir.

🚀 Özellikler
YOLOv8 ile araç türü tespiti (kamyon, otobüs, motor, araba, plaka)
EasyOCR ile plaka okuma
Tkinter ile grafik kullanıcı arayüzü (GUI)
Yasak saatlerde geçiş kontrolü
PostgreSQL veritabanına ihlal kaydı
Kameradan, videodan ve fotoğraftan test edebilme
Gerçek zamanlı araç izleme
🛠️ Kullanılan Teknolojiler
Python
YOLOv8 (Ultralytics)
EasyOCR
OpenCV
Tkinter
PostgreSQL
